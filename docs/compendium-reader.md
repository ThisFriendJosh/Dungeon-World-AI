# Compendium document reader

Saved documents now have an Open document action, searchable text, and section navigation. New uploads retain their original file for download; PDFs also support local page viewing. Older text-only imports can have their original file attached.

The Dungeon Master can consult saved character, scene, dice, timer, and calculation data. Calculations remain previews until changes are applied to a sheet. Save edits before asking about them. The current narrator reads text and structured game data; illustrations require a written description.
