## Presentation views

Orrek has four selectable portrait views; the three kings, cave bear, arcane fox, and two relics have framed token views. These views select image regions for display and do not generate statistics, conditions, sizes, or rules effects.

## Rules and canon

World maps, annotated floor plans, character sheets, and item/bestiary illustrations are retained as reference material. Secret-door floor plans stay in GM references. Printed game text is not a validated rules pack. Existing saved character statistics are never overwritten from an illustration.

## Table styling

The candlelit Dungeon World AI gaming-table image supplies the table and welcome-screen backdrop. The other folios guide parchment panels, brass accents, illustrated codex cards, and restrained celestial details. World/travel maps keep their own illustrated scale in the Art & codex view.
